# About Page Guidelines

## 1. Page Header Pattern
- Pill eyebrow (`ℹ️ Tentang InvestCount`) with clean SVG icon.
- Display headline with brand green accent.
- Hero background: `bg-gradient-to-b from-white via-brand-50/20 to-slate-50`.

## 2. Core Values Grid
- 2x2 grid of responsive cards.
- Each value uses an icon pill badge in `bg-brand-50 text-brand-600`.
- Text is concise without filler words.

## 3. Creator Profile
- Rounded image with `border-2 border-brand-500`.
- Social buttons link out with `Icon name="external-link"`.
