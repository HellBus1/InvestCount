# Transparency Page Guidelines

## 1. Formula Display
- Mathematical calculation formulas must be wrapped in a monospace dark container (`bg-slate-900 font-mono text-slate-100`).
- Formula breakdown: Gross Interest -> Tax (PPh 20%) -> Net Interest.
- Include a concrete, practical IDR calculation example in a tinted callout.

## 2. Regulatory Data Sources
- Clearly cite official regulators (Bank Indonesia, OJK, LPS) with external link icons.
- List update frequency explicitly.
- Include amber-tinted disclaimer card regarding bank rate fluctuations.
